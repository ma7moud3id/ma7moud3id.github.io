```
📁 repo/
 ├── index.html          → portfolio page structure
 ├── styles.css          → portfolio styling
 ├── script.js           → portfolio interactions (i18n, animations, mascot...)
```

Both pages are plain HTML/CSS/JS — no build step, no dependencies. Clone it, open `index.html` in a browser, and it just works.
